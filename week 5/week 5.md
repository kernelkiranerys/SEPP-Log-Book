## Types of Programming Languages

Programming languages can be categorized into:

- **Procedural:** COBOL, Pascal, C  
- **Object-Oriented:** Java, C++, Scala, Kotlin  
- **Multi-Paradigm:** Python, PHP, JavaScript  
- **Functional:** Haskell, Lisp  

Also grouped as:
- **Low-Level:** Machine Code, C  
- **High-Level:** Python, Java

---

## Features That Vary Between Languages

- **Syntax** and readability  
- **Typing strategy:** Static vs. Dynamic  
- **Speed:** Compilation and runtime  
- **Community:** Support, tools, packages  
- **Usage:** Domains and trends  
- **Extensions:** GUI, Web support, etc.

---

## Abstraction in Programming Languages

- Programming languages allow control of CPU, memory, and registers.
- Higher-level languages abstract away machine-level details.
  - **C** still exposes some low-level details.
  - **Python** and **Java** hide most of them.

---

## Object-Oriented Programming (OOP)

- Models the world as **objects** with **attributes** and **behaviors**.
- Benefits include **code reuse**, **inheritance**, and **polymorphism**.
- Works best for large, complex problems with interacting components.

---

## Multi-Paradigm Flexibility

- **Python** supports procedural, object-oriented, and functional styles.
- **Java** enforces OO; procedural coding is discouraged.
- This is why students often start with Python before Java.
