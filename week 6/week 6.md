# Lecture 06: Low-Level Programming


---

## What is a Computer Program?

- A program is a **list of numeric instructions** executed by the **CPU**.
- These instructions are known as **machine code**.
- Each CPU has its own **Instruction Set Architecture (ISA)**.
- Originally programmed via physical media (e.g. punched cards).
- Today, programs are stored in memory (RAM, ROM, Flash, etc.).

---

## Purpose of Programming Languages

- Make programming more accessible and human-readable.
- Programming languages act as **abstraction layers**.
- Advantages:
  - Improved productivity
  - Easier for beginners
  - Hardware portability
  - Optimization through compilers

---

## Evolution of Programming Languages

### Second Generation (2GL) – Assembly

- Uses **mnemonics** to represent instructions.
- Requires an **Assembler** to convert to machine code.
- Still complex, slow, and **not portable**.

### Third Generation (3GL) – High-Level Languages

- Use **English-like syntax** (e.g., C, Python).
- Require a **Compiler** to translate into lower-level code.
- Provide **abstraction**, **portability**, and **faster development**.

---

## Writing Code – Toolchains and IDEs

- Programming process:
  1. Write code
  2. Compile
  3. Run

- A **toolchain** includes compiler, linker, etc.
- **IDEs** (e.g., CLion) combine editing, compiling, and running in one interface.

---

## Learning to Program – Key Skills

- Understanding syntax and structure
- Reading and analyzing existing code
- Debugging syntax and logical errors
- Designing algorithms
- Communicating with other programmers
- Practicing consistently

---

## What is an Algorithm?

- A **set of rules** to solve a problem.
- Core programming involves implementing algorithms using:
  - **Sequence**: Step-by-step execution
  - **Selection**: Conditional logic
  - **Iteration**: Loops and repetition

---

## Reusing Code

- Reuse is common in programming.
- We use **libraries** for pre-written functions.
- Libraries are accessed via **APIs (Application Programming Interfaces)**.
- **Bare-metal** programming refers to code without an operating system.
